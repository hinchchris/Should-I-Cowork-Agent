# Building the Should I Cowork Agent

## Prerequisites

- Microsoft 365 Copilot license
- Access to Agent Builder

## Create the Agent

1. Open Microsoft 365 Copilot
2. Select Create Agent
3. Name the agent "Should I Cowork?"
4. Copy the contents of Description.md
5. Paste into Description
6. Copy the contents of Instructions.md
7. Paste into Instructions
8. Copy the prompts from SuggestedPrompts.md
9. Paste into the Suggested Prompts section 
10. Save the agent

## Test the Agent

Example:

Should I use Cowork to gather customer requirements,
create a project plan, and coordinate with five stakeholders?

Expected Outcome:

The agent should recommend Cowork and explain why.
